# Национальный день — Telegram-бот

Раз в сутки, в 10:00 по рижскому времени, пишет глобальные и американские дни. Праздники, которые отмечают только в одной стране (Россия, Казахстан и другие), не включаются.

Полный каталог американских national days вроде National Pizza Day у Checkiday платный: бесплатный тариф — около 100 запросов в месяц. Здесь используется своя база `days.json` и бесплатные официальные праздники США из Nager.Date.

## Запуск

1. Токен берётся у @BotFather командой `/newbot`.
2. Установите зависимости и запустите:

```bash
cd national-day-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN="123456:токен"
python bot.py
```

По умолчанию `Europe/Riga` и 10:00. Процесс должен работать постоянно: GitHub код только хранит.

## Команды

- `/start` — подписаться
- `/stop` — отписаться
- `/status` — время и число подписчиков

Отдельной команды «прислать сейчас и пропустить утро» нет. Утренняя сводка уходит по расписанию.

Новые дни добавляются в `days.json`: ключ `MM-DD`, у записи поле `scope` — `global` или `us`.
